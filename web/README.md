# 暴打土豆 · 网页版

手机浏览器直接开打的「暴打土豆」。**iOS Safari 优先**，竖屏手机为第一目标，iPad 与桌面浏览器同样可用。

打开即玩：不用登录、不用注册、不用装 App、**没有任何网络请求**（素材全部随页面一起下发，存档只写本机 `localStorage`）。

---

## 玩法

| 操作 | 效果 |
| --- | --- |
| 轻触屏幕任意处 | 暴打一下（触摸一次 = 击打一次，零延迟） |
| 底部 💦 按钮 | 滋水枪；连续滋 5 次把土豆滋湿（4 秒后自己干） |
| 底部 ✋ 按钮 | 竖中指，土豆嫌弃你 |
| 左上「总暴打」 | 累计击打次数（永久保存） |
| 右上 🔊 按钮 | 音量：静音 / 25% / 50% / 75% / 100% |

**连击系统**：6 秒不打，连击清零、土豆变回「正常」。

**六种形态**：连击数跨过 5 个阈值时，土豆依次进化到越来越摆烂的形态。阈值在首次打开时随机生成后永久固定，每台设备都不一样。

**台词**：升级到特定形态、被滋湿、以及 10% 随机概率会触发土豆的语音吐槽。

## 本地试玩

```powershell
.\serve.ps1
```

会同时打印本机地址和局域网地址。手机连同一个 WiFi，用 Safari 打开打印出来的那个 `http://192.168.x.x:8765/` 就能玩（这样音频才正常 —— 直接双击 `index.html` 用 `file://` 打开时浏览器会拦掉 `fetch`，音效会自动降级成 `<audio>` 播放，且部分浏览器不出声）。

自检页在 `/devtools.html`：核对 44 个素材是否加载、14 个音效逐个试听、查看存档、快速触发各种玩法。

## 部署

整个 `web/` 目录就是完整站点，纯静态、零构建。丢到任何静态托管（GitHub Pages / OSS / Vercel）即可。

注意：**只能发布 `web/` 目录**，仓库根目录下的 PC 版（C#/WPF）与 Android 版（Kotlin）源码不参与发布。

---

## 与其它端的关系

本目录是第三个实现。交互、动画、音效时长、形态阈值区间、徽章排版全部**以 Android 版 `MainActivity.kt` 为基准逐条对齐**，与 PC 版（WPF）保持一致。

网页版特有的取舍：

- **DOM + CSS 渲染**，不用 canvas —— 道具按钮和音量菜单本来就得是 DOM，CSS 过渡做弹跳更顺，而且待机时零动画零定时器（省电）。
- **土豆切帧用 13 个预先摆好的 `<img>` 翻 `visibility`**，不是换 `src` —— 换 `src` 会触发重新解码，iOS 连点会闪。
- **Web Audio 播放音效**（不是 `<audio>`）—— 能叠加播放、延迟低，还能拿到精确时长来算台词时间。
- **`pointerdown` 而不是 `click`** —— 消灭 iOS 的 300ms 点击延迟，做到「触摸一次 = 击打一次」。
- **首次进入有一层「轻触屏幕开始」** —— iOS 规定音频必须由用户手势解锁，这一层就是在解锁；这一下不计入击打。
- 存档写不进时（Safari 无痕模式）**静默降级**，游戏照常能玩，只是关掉页面后不记录。
